NavMesh 추격 세팅 TODO - By Codex

목표:
Enemy가 Player를 시야로 감지하면 NavMeshAgent로 Player 위치까지 추격하게 만들기.

1. Enemy 프리팹 확인

대상:
Assets/Prefabs/Enemy/EnemySoldier.prefab

루트 EnemySoldier 오브젝트에 아래 컴포넌트가 있어야 함.

    NavMeshAgent
    EnemyBT
    EnemyFindArea

EnemyBT Inspector:

    _findArea: 같은 오브젝트의 EnemyFindArea
    _agent: 같은 오브젝트의 NavMeshAgent

비워둬도 코드에서 GetComponent로 자동 할당되게 해두었지만,
처음 확인할 때는 직접 드래그해서 넣어도 됨.


2. EnemyFindArea 값 세팅

EnemyFindArea Inspector 추천값:

    _degree: 70
    _distance: 15
    _eyeHeight: (0, 1.6, 0)
    _targetHeight: (0, 1.0, 0)
    _playerLayer: Player
    _obstaclesLayer: Ground, Object, Maps 등 시야를 막아야 하는 레이어

주의:
Player 오브젝트의 Layer가 Player인지 확인해야 함.
Tag가 아니라 Layer임.


3. NavMeshAgent 값 세팅

NavMeshAgent 추천값:

    Speed: 3.5
    Angular Speed: 120
    Acceleration: 8
    Stopping Distance: 1.5
    Auto Braking: On

Stopping Distance가 0이면 Player 위치까지 너무 바짝 붙으려고 할 수 있음.


4. NavMeshSurface 만들기

씬 안에 빈 오브젝트 생성:

    GameObject 이름: NavMeshSurface

NavMeshSurface 컴포넌트 추가.

기본 체크:

    Agent Type: Humanoid
    Collect Objects: All 또는 Volume
    Use Geometry: Render Meshes 또는 Physics Colliders
    Include Layers: Ground/Maps/Object 등 걸어갈 바닥이 포함되어야 함

그 다음 Bake 버튼으로 NavMesh 생성.

씬 뷰에서 바닥 위에 파란 영역이 보이면 NavMesh가 깔린 것.


5. 테스트 순서

1. Enemy를 NavMesh 파란 영역 위에 배치
2. Player도 같은 NavMesh 근처에 배치
3. Play 실행
4. EnemyFindArea의 Gizmo 파란 원 안에 Player가 들어가는지 확인
5. Player가 Enemy 전방 시야각 안에 있으면 선이 초록색으로 보이는지 확인
6. 초록색으로 보이면 Enemy가 Player 쪽으로 이동하는지 확인


6. 안 움직일 때 먼저 볼 것

Console에 이런 에러가 있는지 확인:

    SetDestination can only be called on an active agent that has been placed on a NavMesh

이 경우:

    Enemy가 NavMesh 파란 영역 위에 없음
    NavMeshSurface Bake가 안 됨
    바닥 레이어가 NavMeshSurface Include Layers에 빠짐


Player를 못 찾는 경우:

    Player Layer가 Player인지 확인
    EnemyFindArea _playerLayer가 Player인지 확인
    _distance가 너무 작지 않은지 확인
    _degree가 너무 작지 않은지 확인
    장애물 레이어가 Player까지 막고 있지 않은지 확인


7. 현재 코드 흐름

EnemyBT
    -> CanSeePlayerNode
        -> EnemyFindArea.IsDetectedPlayer가 true면 Success
    -> ChasePlayerNode
        -> NavMeshAgent.SetDestination(EnemyFindArea.DetectedTarget.position)

CanSeePlayerNode, ChasePlayerNode는 프리팹에 붙이는 컴포넌트가 아님.
EnemyBT가 내부에서 new로 만들어서 쓰는 Behavior Tree 노드임.
